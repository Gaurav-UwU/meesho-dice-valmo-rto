# Valmo Rescue Console

Team GPS (IIT Bombay), Meesho DICE 3.0. A working prototype for reducing RTO (return to origin) at the last mile:
a ₹15 Rescue Bonus on the hardest orders, attempt verification with a hub captain, two-way WhatsApp for customers,
a Refused-Parcel Router, and a paired-rider pilot that decides GO / RE-PRICE / KILL.

- **Try it:** https://valmo-rescue-console.vercel.app (demo mode, no sign-in)
- **Code and how to run it:** [`prototype/`](prototype/README.md)

Not an official Valmo or Meesho app. All orders, riders and outcomes are synthetic.
